# Prompt: Support Go

Je voudrais preparer une spec Speckit pour etendre les capacites de Spaghetti Compass au langage Go.

On veut avoir les memes commandes que les langages actuels, mais adaptees au langage Go:

- `explore` sur un fichier `.go`;
- `explore` sur une fonction ou methode Go;
- `impact` sur un fichier `.go`;
- sorties texte et JSON compatibles avec le format existant;
- navigation precise quand possible.

Exemples de code Go a prendre en compte:

- `~/code/MODELO_HUB/modelo-broker-pa`
- `~/code/MODELO_HUB/bill-e`

Note de preparation: le second chemin local observe est `~/code/MODELO_HUB/modelo-bill-e`.
